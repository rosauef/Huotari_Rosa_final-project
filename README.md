# RecipeFinder

This is a React web application for searching recipes, viewing the recipe details and saving favorite recipes.

## Technologies

- React
- React Router
- Bootstrap
- TheMealDB API

## Installation

Install dependencies:
npm install

## Run development server

npm run dev

## Build Project

npm run build
